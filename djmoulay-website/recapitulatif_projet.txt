3. PROCEDURES ET MISES EN LIGNE
------------------------------------------------------------------------

A. POUR METTRE EN LIGNE SUR NETLIFY (Gratuit) :
1. Créez un compte sur https://www.netlify.com/
2. Allez dans l'onglet "Sites" et glissez-déposez le dossier de projet complet 
   "djmoulay-website" dans l'encadré de déploiement en bas de page.
3. Le site est instantanément en ligne sous un lien temporaire Netlify.

B. POUR METTRE A JOUR LE SITE APRES UNE MODIFICATION :
1. Ouvrez votre projet sur Netlify.
2. Allez dans l'onglet "Deploys".
3. Glissez-déposez à nouveau le dossier "djmoulay-website" mis à jour.

C. POUR CONNECTER VOTRE DOMAINE IONOS A NETLIFY :
1. Sur Netlify, allez dans "Site Configuration" > "Domain Management" > "Add a Domain".
2. Saisissez votre domaine (ex: djmoulay.com).
3. Netlify vous indiquera de pointer votre DNS.
4. Connectez-vous sur IONOS, allez dans les paramètres DNS de votre domaine et :
   - Modifiez l'enregistrement A (nom @) pour pointer vers l'IP de Netlify (75.2.60.5).
   - Modifiez l'enregistrement CNAME (nom www) pour pointer vers votre adresse netlify.app.
5. Une fois propagé, Netlify activera le HTTPS sécurisé automatiquement.

D. PREMIERE UTILISATION DU FORMULAIRE :
1. Lors du premier envoi de test du formulaire sur votre site en ligne, vous 
   recevrez un e-mail de FormSubmit sur contact@djmoulay.com.
2. Cliquez sur le bouton "Activate" de cet e-mail pour activer la boîte.
3. Toutes les réservations suivantes arriveront directement dans vos e-mails.
